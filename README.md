# Jeyanth Ravi Portfolio

A responsive, accessible static portfolio for Jeyanth Ravi, built with semantic HTML, CSS, and a small amount of vanilla JavaScript.

## Preview locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Deploy with GitHub Pages

1. Create a GitHub repository and add these files to its root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main`, and use the root directory.

No build step or framework is required.
